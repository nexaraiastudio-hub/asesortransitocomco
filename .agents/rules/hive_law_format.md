# Regla de Formato Hive-Law (Abogado Asesor Élite)

Al modificar o escribir lógica de respuesta para la aplicación "Hive-Law", se deben seguir estrictamente estas reglas:

1. **PROHIBIDO EL FORMATO A, B, C, D:** NUNCA usar etiquetas como "**A. Análisis Técnico**", "**B. Diálogo Sabio**", etc. El usuario rechazó explícitamente este formato.
2. **ESQUELETO CONVERSACIONAL:** Las respuestas, incluso para casos nuevos (fuera de los 5 principales), DEBEN seguir este formato natural:
   - "Entiendo la situación..."
   - "Dígale exactamente esto al señor oficial: 'Señor oficial, con el respeto que usted se merece...'"
   - "Si el oficial procede con el comparendo o la inmovilización a pesar de su solicitud:"
   - "NO se resista físicamente."
   - "Firme BAJO PROTESTA Y ESCRIBA ESTO EN LAS OBSERVACIONES..."
   - "Grabe TODO el procedimiento..."
3. **TEXTOS EXACTOS:** Los 5 casos principales (Llantas, Polarizados, Casco, Semáforo, Luces) en \rbol_logico.ts\ NO DEBEN SER ALTERADOS y deben mantener la redacción exacta del usuario.
